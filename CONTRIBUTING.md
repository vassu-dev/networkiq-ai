# 🤝 Contributing

Thank you for your interest in contributing to **NetworkIQ AI**.

## Development Workflow

1. Fork the repository

2. Create a feature branch

```bash
git checkout -b feature/your-feature
```

3. Commit changes

```bash
git commit -m "feat: add demand forecasting"
```

4. Push

```bash
git push origin feature/your-feature
```

5. Open Pull Request

---

## Coding Standards

- Follow PEP8
- Use meaningful variable names
- Write reusable code
- Add documentation
- Write unit tests

---

## Pull Request Checklist

- Code Compiles
- Tests Passing
- Documentation Updated
- No Sensitive Data
